Export a PDF or Anki deck

Generates a randomised set of questions and bundles them for offline practice. The questions are shuffled, and within each question the option letters are shuffled too, so the correct letter is not the same as in the database. Generation runs server-side via make_pdf.py / make_anki.py; when it finishes you'll get a download link.

Generated files live in the downloads/ folder next to app.py and are also reachable from the link the next page produces. Older files are not automatically deleted — clean up the folder when you're done.
